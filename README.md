# 🎯 스나이퍼프로 (SniperPro)

키움증권 OpenAPI+ 기반 기술적 분석 스크리너 & 자동매매 도구

---

## 📥 다운로드

**[➡ 최신 버전 다운로드 (Releases)](../../releases/latest)**

설치파일: `SniperPro_Setup_<버전>.exe`

---

## ⚠️ 사전 준비 (필수)

이 프로그램을 사용하려면 **다음 4가지가 모두 준비**되어 있어야 합니다:

### 1. Windows PC
- Windows 10 / 11 (64비트 또는 32비트)
- 인터넷 연결

### 2. 키움증권 계좌
- 영웅문 가입 → 계좌 개설 (실계좌 또는 모의투자)

### 3. 키움 OpenAPI+ 사용 신청
- 영웅문 HTS 로그인 → 상단 메뉴 **온라인업무** → **OPEN API** → **사용 신청**
- 신청 후 1~2 영업일 승인 대기

### 4. 키움 OpenAPI+ 프로그램 설치
- [키움증권 홈페이지 → Open API → OpenAPI+ 다운로드](https://www.kiwoom.com/h/customer/download/VOpenApiInfoView)
- 다운로드한 설치 파일 실행 → 설치
- ⚠️ 설치 후 한 번 OpenAPI+ 로그인 화면을 띄워서 **자동 업데이트**까지 완료해 두세요

---

## 🚀 설치 방법

1. 위 **다운로드** 링크에서 `SniperPro_Setup_<버전>.exe` 받기
2. 다운로드한 .exe 더블클릭
3. ⚠️ "Windows가 PC를 보호했습니다" 경고가 뜨면:
   - **추가 정보** 클릭 → **실행** 클릭
   - (코드 서명 인증서 미적용으로 인한 정상 경고입니다)
4. 설치 마법사 진행 (한국어 선택)
5. 설치 완료 후 자동 실행 → 키움 로그인 창 등장

---

## 💡 첫 실행 가이드

1. **로그인**: 키움증권 ID / 비밀번호 입력
2. **모의투자 권장**: 처음에는 모의투자 계좌로 충분히 테스트
3. **설정 탭** → 텔레그램 알림 등 입맛에 맞게 설정
4. **스나이핑 탭** → 스크리닝 실행

---

## 🔄 업데이트 방법

새 버전이 출시되면 프로그램 시작 시 **자동으로 알림이 뜹니다**.
- "예" 누르면 다운로드 페이지로 이동
- 새 설치파일 받아서 다시 설치하면 끝 (기존 설정/데이터 유지)

수동 확인은 [Releases](../../releases) 페이지에서.

---

## ⚠️ 주의사항 (꼭 읽어주세요)

- 이 프로그램은 **투자 참고용**이며, 모든 투자 결정과 책임은 **본인에게 있습니다**.
- **자동매매는 반드시 모의투자로 충분히 테스트한 뒤** 실계좌에 적용하세요.
- 키움 OpenAPI 정책상 분당/초당 요청 제한이 있어 과도한 사용 시 일시 차단될 수 있습니다.
- 본 프로그램은 키움증권 공식 제품이 아닌 **서드파티 도구**입니다.
